ArtistFin: Know Your Artists

Fills artist bios, images, and profile details. The scheduled task only fills what is missing. Use the button below to queue a full refresh.

Data providers

Checked providers run in list order and merge with first-wins per field. Whatever they return (bio, images, genres, hometown, dates, website) is written automatically. MusicBrainz is best for IDs / hometown / genres; TheAudioDB for images; Wikipedia for bios; Deezer for high-res primary art.

Refresh

Queues ArtistFin: Refresh All Artists under Dashboard --> Scheduled Tasks.
Advanced
Concurrent artists. Keep low (MusicBrainz / Wikipedia prefer polite clients). 0 or 1 recommended. Max 4.
